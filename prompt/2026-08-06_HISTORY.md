# 2026-08-06 — Prompt history

## Sortable issue IDs

**Prompt:** hiện tại https://team.linkadz.store/issues/BUG-ESP4F4T các id của các task or backlog nó đang gen tùm lum, như jira, trello thì các ticket khi được tạo ra được đánh số hay thứ tự, tao muốn có thể sort theo ID, thì mày có thể cải thiện id này có thể sort được không, các ticket mới được tạo ra tiếp theo còn các ticket cũ vẫn giữ nguyên

**Decisions:**
- Per-team prefix via a new editable `Team.refPrefix` (ENG-1, QC-1), frozen after the team's first issue.
- Sequential numbering for issues, roadmap items (RM-n) and docs (DOC-n), using the existing unused `CounterService`.
- Sort key stored as derived `refPrefix`/`refSeq` on the issue — never parsed from the ref string.
- Legacy rows are never written to; they sort as one `createdAt`-ordered block.

**Spec:** docs/superpowers/specs/2026-08-06-sortable-issue-ids-design.md

**Gap review (2nd pass):** found 12 gaps in the first draft — the biggest being that
`order` (kanban drag position) leads the list sort and would have made the sort control
a no-op. Also: reserved prefixes (DOC/RM/TSK/BUG share a counter key), counter-based
freeze instead of issue-count, prefix uniqueness across archived teams, mapper/schema
round-trip for the derived fields, and an optional shell prop so the 13 IssueBoardLayout
consumers don't break. All folded into the spec plus a risk register.

**Implementation plan:** docs/superpowers/plans/2026-08-06-sortable-issue-ids.md — 16 tasks, 86 steps,

standalone `scripts/backfill-team-ref-prefix.ts` (matching the repo's dry-run/--apply backfill
convention) rather than a boot hook, and `refPrefix` is optional with a TSK/BUG mint fallback so
deploying before the backfill runs is safe.

**Plan gap review:** verified every file/method the plan named against the code; 7 corrections.
The dangerous one: the team PATCH handler maps every non-TEAM_DEFAULT_LOCKED failure to 404 (inverse

team.dtos.ts; TeamResponseDto must expose refPrefix/refPrefixLocked; sequentialRef's throw needs
catching into a Result; test helpers need a real UniqueEntityID; roadmap's mint sits in a .map that
