## Attachments: cho phép gắn file ZIP

**Prompt:** [Image #9] vui lòng hổ trợ gắn file zip

**Kết quả:**
- Backend: thêm `zip → application/zip` vào `DOCUMENT_TYPE_BY_EXT` (`upload-kind.ts`) — ZIP tính là "document", dùng giới hạn dung lượng của document. Trình duyệt Windows gửi `application/x-zip-compressed` nhưng phần mở rộng quyết định nên vẫn lưu là `application/zip` (chỉ tải về, không render → an toàn khi phục vụ qua URL public). Cập nhật thông báo lỗi; thêm test.
- Frontend `AttachmentBar`: hộp chọn file nhận `.zip`, icon `FileArchive` cho file nén; i18n hint (en/ko) nhắc ZIP.
