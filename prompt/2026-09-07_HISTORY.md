## Khảo sát

- **Backend đã có sẵn**: `Issue.attachments` (`issue.props.ts`, `issue.entity.ts`, persist ở
  `issue.schema.ts` + `issue.repository.ts`), `UpdateIssueDto.attachments` (validate qua
  `IssueAttachmentDto`) và `IssueResponseDto.attachments`. Không có nhánh nào chặn theo kind —
  task cũng lưu được, chỉ là mô tả Swagger ghi nhầm "(bug)".
- **Frontend là chỗ thiếu**: không màn nào render `issue.attachments`. Chỉ comment có đính file
  (`CommentThread` + `useMediaAttachments`), đúng như ảnh chụp.
- `TaskDto` (frontend) thiếu hẳn field `attachments` dù task đọc chính `/issues` (nên response
  vẫn luôn trả về).
- Đã có sẵn UI đính file hoàn chỉnh ở Docs: `DocAttachments.tsx` (chips + drag/drop + hàng
  progress), dựng trên `MediaUploader` + `useUploadQueue` + `POST /v1/uploads`.

## Đã làm (UI only, không đụng schema/migration)

- Nâng `features/docs/components/DocAttachments.tsx` thành component dùng chung
  `components/AttachmentBar.tsx` (type `AttachmentFile` = shape của `DocAttachment`/`BugAttachment`).
  Docs (`DocPageEditor`, `PublicDocPage`) trỏ sang bản chung; xoá file cũ.
- i18n: `docs.addFile|fileRemove|filesHint` → `attachments.title|add|remove|hint` (en + ko).
- `IssueDetailMain`: thêm props `attachments` + `onSaveAttachments`, render section
  **ATTACHMENTS** (eyebrow heading + count, giống SUB-TASKS / DOCS) giữa description và
  Sub-tasks. Không có `onSaveAttachments` ⇒ read-only; rỗng + read-only ⇒ không render.
- Wire: `TaskDetail`, `BugDetail` (`save({ attachments })`), `PublicIssueDialog` (chỉ đọc).
  Nhờ dùng chung `IssueDetailMain`, peek drawer và inbox pane có luôn.
- Types: thêm `attachments` vào `TaskDto` và `UpdateTaskInput`.
- Backend: sửa mô tả Swagger `attachments` từ "(bug)" → áp dụng cho mọi issue.
